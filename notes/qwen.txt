
🚀 Your Copy-Paste Workflow Template
Step 1: Start a New Chat
Upload manifest.json and new-chat.md. Then send this exact prompt:

I am ready to generate a lesson. The target lesson path is: lessons/basics/where-is.json. Please read the manifest, apply the rules from new-chat.md, use the <planning> scratchpad, and output the valid JSON.

Step 2: Run the Validator
Save the LLM's output to lessons/basics/numbers.json and run:
node tools/validate-lessons.js lessons/basics/numbers.json
Step 3: Handle the Result

    If it says ✅ SUCCESS!: You are done. Move on to the next lesson and start a brand new chat.
    If it fails: Copy the 📋 VALIDATION REPORT from the terminal. Start a new message in the same chat and say:

The validator returned these errors. Please fix the JSON and output only the corrected code block:
[Paste the error report here]

(Note: If a lesson fails validation more than 2 times in the same chat, abandon that chat entirely and start a fresh one. This resets the model's attention and almost always yields a perfect result on the first try).
